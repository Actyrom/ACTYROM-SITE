INSTALLATION MANUELLE SUR GITHUB
1. Sauvegarder votre dépôt actuel si vous souhaitez pouvoir revenir en arrière.
2. Envoyer tous les fichiers et dossiers de ce pack à la RACINE du dépôt ACTYROM-SITE.
3. Remplacer les fichiers existants portant le même nom.
4. Conserver le dossier assets/ avec style.css, app.js et logo-actyrom.svg.
5. Supprimer le fichier racine "CONNEXION" sans extension s'il existe encore : le site utilise connexion.html.
6. Vérifier GitHub Pages puis actyrom.fr après le commit.
